# X行动 · OPERATION X

一款参照《三角洲行动》烽火地带（危险行动）玩法制作的第一人称战术撤离网页游戏。
基于 Three.js + Vite，无需任何服务器，浏览器打开即玩，支持电脑（键鼠）与平板（触屏双摇杆）两种模式。

## 地图

| 地图 | 氛围 | 关键区域 |
| --- | --- | --- |
| 潮汐监狱 | 夜战 | 监区牢房（铁栅栏）/ 工坊 / 放风场集装箱区 / 四角哨塔 / 码头 |
| 零号大坝 | 黄昏沙漠 | 坝顶机房（可进入）/ 泄洪道闸房 / 行政辖区 / 村庄 / 电站 / 集装箱装卸区 / 直升机坪 |

每局出生点与撤离点（3 个候选）随机刷新；物资箱（14 个）与加密保险箱（2 个）每局重新随机布置。

## 随机事件

每局开局抽签，动态改变战场态势：

- **坠机残骸**：随机位置刷新直升机残骸（冒烟），附近有 2 个高价值物资箱和 2 名看守
- **空投补给**：开局约 30-60 秒后在随机点投放金色信标物资箱（小地图菱形标记 + 飞机掠过音效）
- **看守增援**：开局约 1-1.5 分钟后一支 3 人小队从地图边缘向你扑来（警笛预警）

## 情报档案（环境叙事）

每张地图藏有 4 份发光的情报档案（监狱长日志、加密电报、巡逻记录等），拾取后阅读碎片化的背景故事，
HUD 显示收集进度，撤离结算计入档案数——集齐它们才能拼出「潮汐监狱」与「零号大坝」到底发生了什么。

## 画面与反馈

- 天空穹顶渐变（监狱深夜蓝 / 大坝黄昏橙）+ 日月光盘、700 颗星点、夜间雾效
- 程序化照片风纹理（混凝土/灰浆/瓦楞集装箱/做旧金属/木板/沙地）+ PMREM 环境光照 + 泛光后期
- 动态分辨率：帧率不足自动降档，空闲时恢复（桌面端可用 `?ssao` 实验性开启 SSAO）
- 敌人铰接动画：髋/肩枢轴摆动、交战举枪、跑动前倾、受击踉跄、倒地
- 命中反馈：血雾粒子、墙面弹孔与扬尘、爆头金色/躯干白色/击杀红色三态命中标记、
  分层命中音效（爆头叮声/躯干闷响/击杀低音）、受击方向弧线指示

## 玩法（与三角洲行动相同的撤离逻辑）

- 孤身渗透被潮水环绕的废弃监狱「潮汐监狱」
- 每局随机布置 14 个物资箱，收集机械零件、金条、军用硬盘等有价值的物资
- 每局另有 2 个加密保险箱：参照原作密码转盘机制破解（指针进绿区锁定 ×3），
  内含翡翠原石、金鹰雕像等高价值物资；破解中不能移动，被击中会中断
- 击退 10 名武装看守 AI（会巡逻、察觉、包抄、齐射；爆头伤害 ×2.2）
- 武器有渐进后坐力：连射准星逐渐上跳且累积加速，需要手动压枪
- 抵达码头绿色光柱撤离点，停留 5 秒完成撤离即获胜
- 被击倒则行动失败，搜刮到的物资全部丢失

## 双端操作

| 模式 | 操作 |
| --- | --- |
| 电脑模式 | WASD 移动 · 鼠标视角/左键射击 · 右键开镜（狙击枪）· Q 切换武器 · Shift 疾跑 · C 蹲伏 · 空格跳跃 · R 换弹 · E/F 搜刮 |
| 平板模式 | 左侧虚拟摇杆移动（推满疾跑）· 右半屏滑动转视角 · 射击/跳/蹲/换弹/互动/切枪/开镜按钮 |

## 武器

- **AS VAL 突击步枪**（初始）：全自动，30 发弹匣 + 120 备弹，渐进后坐力需压枪
- **M700 狙击枪**（仅从物资箱随机获取，含 10 发弹）：栓动高威力，命中一发即可击倒目标；
  右键/开镜键放大瞄准镜（开镜近乎零散布，腰射扩散很大），额外的狙击弹也可从宝箱获取

## 画面特性

- ACES 电影级色调映射 + UnrealBloom 泛光后期
- PCF 软阴影月光平行光 + 多盏点光源（走廊顶灯、哨塔灯、场地灯）
- 夜间雾效、程序化波浪 + 缓慢潮汐上涨的环岛海水
- PBR 材质、第一人称枪模（后坐/换弹/枪口火光/曳光弹）

## 运行

```bash
npm install
npm run dev      # 开发：http://localhost:5173
npm run build    # 产物输出到 dist/，任意静态服务器可托管
npm run preview  # 本地预览构建产物
```

## 结构

```
src/
  main.js      # 主循环、玩家物理、命中判定、撤离流程
  world.js     # 潮汐监狱地图（监区/工坊/放风场/码头）+ 碰撞与射线
  controls.js  # PC 键鼠 + 平板触屏双摇杆
  weapons.js   # 枪模、射击、换弹、曳光
  enemies.js   # 武装看守 AI（巡逻/交战状态机）
  loot.js      # 物资箱与撤离点
  hud.js       # HUD、小地图（旋转式，含敌人/物资/撤离标记）
  audio.js     # WebAudio 合成音效（枪声/脚步/拾取/环境海风）
```
